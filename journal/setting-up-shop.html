Setting up shop.

News · Jun 2026

( All entries )

News By CCC Jun 2026

Before the first project, there was a room. A few desks, a lot of cables, and a list of things we wanted to do differently.

We chose to build CCC in Indonesia because this is where we are from, and because we think the work made here deserves to sit beside anything made anywhere else. Place shapes taste. The light, the language, the way people gather. We want that to show up in what we make.

Building the room

Setting up shop meant small, unglamorous decisions. Which tools we would use. How we would share files. How a brief moves from one person to the next without losing its meaning. None of it is visible in the final work, but all of it is in there.

A studio is a set of habits before it is a space.

We are still building. The room will change, and so will we. The standard won't.
